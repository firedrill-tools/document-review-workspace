# Working rules

Keep this a standalone synthetic document review app. The CopilotKit/Claude agent may inspect and propose edits, but only the operator decision endpoint can change committed text. Every approval must recheck the target section revision and original text; unrelated sections and documents must remain unchanged. A rejected proposal changes no document text. Protected sections cannot be edited. Do not claim offline tests prove live Claude chat. Add Firedrill only against the qualified new release.


Validate bounded strict document/proposal identities and relationships on read and before write. Decision revisions reject bools/floats/strings/unsafe integers; HTTP extra fields fail. Keep the persistent sidecar lock inode (never unlink it) and unique 0600 atomic temp publication. Advisory ownership covers cooperating POSIX callers, not outside editors. Preserve untouched documents/sections and remove only the current writer's temp on failure. In-memory chat still runs in one API process. Native execution is owned by runtime.py; never construct ambient model/client/checkpointer dependencies in build_agent. Native JSON is checked before dispatch, provider SSE is disabled, and AG-UI RUN_FINISHED requires a completed final response and persisted receipt. Keep true async tools, current-run source bindings and inside-publication deadline/cancellation guards. Every run owns a durable thread/run receipt and run-only checkpoints; reject repeat IDs before another model, preserve actual proposal effects after failure and never attribute operator text changes to the model. Source history/imports and exact pending proposal recovery are not fresh model effects. The private HTTPX2 client belongs to the API lifespan, including cancellation/shutdown/startup cleanup. Do not patch vendor caches/source or add a global model.

88 backend checks and six production Chromium flows (two full native chat, four state/navigation checks) qualify controlled native HTTP/UI behavior, not live Claude judgment. Keep ready/error UI, selected-document read fencing, source HTML sanitization/URL hardening and KaTeX matching CSS. Test with the production build and real bridge. Twelve hash-bound backend/data cases validate human import UTC times, source/approval history and exact populations; manifest focus never enters prompts. Private initialization refuses existing files/symlinks. New model effect attribution binds thread and run; preserve unknown legacy metadata. Keep busy search, stale approval warning/rejection and noncontiguous selection. Bundle data in backend wheel/sdist, regenerate deterministically and run the root distribution verifier outside checkout, including the complete frontend source archive. PLAN.md records remaining external gates.
